# LabWork4

## Описание
Консольное приложение на C# для измерения времени выполнения разных задач и логирования результатов в файл.

## Инструкция по установке
1. Скачайте и установите пакет официального SDK .NET 10
2. Склонируйте репозиторий
```bash
git clone https://github.com
```
3. Перейдите в корневую директорию проекта
```bash
cd LabWork4
```

## Использование
1. Для сборки приложения введите в консоль
```bash
dotnet run
```

## Системные требования
* **Платформа выполнения**: .NET Runtime 10.0+ (LTS)
* **ОС**: Windows 10/11
